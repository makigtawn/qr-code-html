# Frontend Mentor - QR Code Component

A responsive QR code card component built with semantic HTML5 and modern CSS3.

![Design preview](./preview.jpg)

## Features
- **Semantic HTML5** structure (`<main>`, `<article>`, descriptive headings, accessible `alt` text)
- **Responsive design** optimized for both mobile and desktop screens
- **Modern CSS** with custom properties (variables), Flexbox centering, and smooth hover interactions

## Built With
- Semantic HTML5 markup
- CSS3 (Custom properties, Flexbox)
- [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) font
